# Changelog

All notable changes to `authmd-laravel` will be documented in this file.

## 0.1.0 - 2026-09-08

- Initial release
- Anonymous and service_auth identity flows
- Claim ceremony with device-authorization pattern
- JWT signing (Ed25519 and RSA256)
- Token exchange (RFC 7523) and revocation (RFC 7009)
- Discovery endpoints (PRM, AS metadata, JWKS)
- auth.md file generation
